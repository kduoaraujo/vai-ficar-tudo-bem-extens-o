# 9. Relatório Final de Extensão Universitária

**Projeto:** Vai Ficar Tudo Bem – Plataforma Virtual de Apoio Emocional  
**Aluno:** Carlos Eduardo Araújo da Silva  
**Curso:** Análise e Desenvolvimento de Sistemas  
**Instituição:** Gran Faculdade  
**Data:** Maio/2026

## 1. Introdução

Este relatório apresenta o desenvolvimento do projeto de extensão “Vai Ficar Tudo Bem”, uma plataforma virtual humanizada de apoio emocional.

## 2. Objetivos Alcançados

- ✅ Desenvolver uma plataforma web com foco em usabilidade e empatia.
- ✅ Aplicar os conhecimentos de Análise e Desenvolvimento de Sistemas (requisitos, UML, modelagem, testes).
- ✅ Criar uma interface acolhedora e acessível.
- ✅ Planejar ações de extensão para impacto social.

## 3. Metodologia

O projeto foi desenvolvido utilizando a metodologia ágil (incremental), com as seguintes etapas:
- Levantamento de requisitos
- Modelagem (UML e MER)
- Prototipação de telas
- Definição da stack tecnológica
- Planejamento de testes e divulgação

## 4. Resultados Técnicos

- Documentação completa do projeto (9 documentos)
- Protótipo de telas com design humanizado
- Modelagem de dados e arquitetura definida
- Plano de testes elaborado
- Repositório organizado no GitHub

## 5. Aspecto Humanizado

O grande diferencial deste projeto foi o cuidado com a experiência do usuário:
- Linguagem empática em toda a interface
- Cores suaves e acolhedoras
- Opção de uso anônimo
- Botão de emergência sempre visível
- Prompts de reflexão guiados

## 6. Impacto Social Esperado

A plataforma tem potencial para ajudar pessoas que enfrentam dificuldades emocionais, oferecendo um espaço seguro, gratuito e acessível 24 horas por dia.

## 7. Dificuldades Encontradas e Aprendizados

- Desafio: Balancear complexidade técnica com simplicidade de uso.
- Aprendizado: A importância de colocar o ser humano no centro do desenvolvimento de sistemas.

## 8. Conclusão

O projeto “Vai Ficar Tudo Bem” demonstra que é possível desenvolver sistemas técnicos com alta qualidade e, ao mesmo tempo, com profundo respeito e cuidado com as pessoas. Esta atividade de extensão uniu conhecimento técnico e responsabilidade social.
