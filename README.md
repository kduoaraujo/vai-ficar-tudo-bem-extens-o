## 📋 Sobre o Projeto

O **Vai Ficar Tudo Bem** é uma plataforma web humanizada que oferece apoio emocional, escuta acolhedora e um espaço seguro para quem precisa desabafar ou buscar conforto.

O objetivo é unir tecnologia com empatia, criando um ambiente virtual inclusivo e acolhedor para qualquer pessoa que precise de suporte emocional.

## ✨ Funcionalidades Principais

- Cadastro e login (com opção de uso anônimo)
- Registro diário de emoções
- Diário Emocional com prompts guiados
- Salas de conversa temáticas (em tempo real)
- Biblioteca de conteúdos sobre saúde mental
- Botão de ajuda urgente com recursos de emergência
- Interface acolhedora e acessível

## 🛠 Tecnologias Utilizadas

- **Frontend:** React.js + Tailwind CSS
- **Backend:** Node.js + Express
- **Banco de Dados:** PostgreSQL
- **Tempo Real:** Socket.io
- **Hospedagem:** Vercel / Railway
