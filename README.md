## 📋 Sobre o Projeto

O **Vai Ficar Tudo Bem** é uma plataforma web humanizada que oferece apoio emocional, escuta acolhedora e um espaço seguro para quem precisa desabafar, refletir ou buscar conforto.

O principal objetivo é unir **tecnologia com empatia**, criando um ambiente virtual inclusivo, acessível e acolhedor.

## ✨ Funcionalidades Principais

- Cadastro e login (com opção de uso totalmente anônimo)
- Registro diário de emoções com emojis
- Diário Emocional com prompts guiados
- Salas de conversa temáticas em tempo real
- Biblioteca de conteúdos sobre saúde mental
- Botão de "Preciso de ajuda urgente"
- Interface com design emocional e acolhedor

## 🛠 Tecnologias Utilizadas

- **Frontend:** React.js + Tailwind CSS
- **Backend:** Node.js + Express
- **Banco de Dados:** PostgreSQL
- **Tempo Real:** Socket.io
- **Hospedagem:** Vercel / Railway
