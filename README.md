## 📋 Sobre o Projeto

O **Vai Ficar Tudo Bem** é uma plataforma web humanizada que oferece **apoio emocional**, escuta acolhedora e um espaço seguro para quem precisa desabafar ou buscar conforto.

Aqui a tecnologia é colocada a serviço do bem-estar, com design empático, interface acolhedora e foco no ser humano.

## ✨ Principais Funcionalidades

- ✅ Uso anônimo ou com cadastro
- ✅ Registro diário de emoções
- ✅ Diário Emocional com prompts guiados
- ✅ Salas de conversa temáticas em tempo real
- ✅ Conteúdos educativos sobre saúde mental
- ✅ Botão de ajuda urgente sempre visível

## 🛠 Tecnologias

- **Frontend:** React.js + Tailwind CSS  
- **Backend:** Node.js + Express  
- **Banco:** PostgreSQL  
- **Tempo Real:** Socket.io
